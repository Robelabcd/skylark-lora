# Skylark LoRA: Teaching a Small Open LLM to Call Tools

Final project for CSCI 6366 (Neural Networks and Deep Learning), George Washington University, Fall 2026.

## Summary

**Skylark** is an AI airline assistant: users ask for flights in plain language, and the assistant must turn each request into the right *tool call*, for example `search_flights(origin="IAD", destination="SEA", departure_date="2026-12-04")`, or decide to ask a clarifying question, decline, or answer directly.

This project fine-tunes a small open model, **Qwen3-1.7B**, for that task using **LoRA (Low-Rank Adaptation) implemented from scratch in PyTorch** and verified against Hugging Face PEFT. It compares the fine-tuned model with prompting baselines and a commercial model on accuracy, latency and cost.

**Results so far:** before fine-tuning, Qwen3-1.7B answers 40% of the 100 test cases correctly zero-shot and 44% few-shot, with 100% valid JSON. Its errors are judgment and knowledge (airport codes, dates, when to ask or decline), not formatting.

## Data and model sources

No external dataset is used; all data was created for this project.

| What | Source |
|---|---|
| Test set (100 cases) | Written for this project: [`data/eval/test_set.json`](data/eval/test_set.json), guide in [`docs/test_set_guide.md`](docs/test_set_guide.md) |
| Training data (4,000 + 400 dev) | Generated by code in this repo: [`src/skylark_lora/datagen/`](src/skylark_lora/datagen/), described in [`docs/data.md`](docs/data.md) |
| Airport codes | IATA codes, compiled by hand in [`airports.json`](src/skylark_lora/datagen/airports.json) |
| Base model | [Qwen/Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B) on Hugging Face (Apache 2.0) |

## Setup

```bash
git clone https://github.com/Robelabcd/skylark-lora.git
cd skylark-lora
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev,train]"
python -m pytest
python -m skylark_lora.datagen.build
```
